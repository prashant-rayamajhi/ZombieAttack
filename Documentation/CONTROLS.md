# 操作方法

## コントローラー

- 移動：左スティック
- カメラ操作：右スティック
- 攻撃／射撃：RT（右トリガー）
- エイム：LT（左トリガー）
- リロード：X
- ジャンプ：A
- 回復アイテム使用：Y またはD-pad下
- Pistolへ切り替え：D-pad左
- ARへ切り替え：D-pad上
- Knifeへ切り替え：D-pad右
- 前の武器へ切り替え：LB（左ショルダー）
次の武器へ切り替え：RB（右ショルダー）

## キーボード・マウス

- 移動：W／A／S／D
- カメラ操作：マウス移動
- 攻撃／射撃：マウス左クリック
- エイム：マウス右クリック長押し
- リロード：R
- ジャンプ：Space
- 回復アイテム使用：H
- Pistolへ切り替え：1
- ARへ切り替え：2
- Knifeへ切り替え：3
武器を順番に切り替え：マウスホイール
